# OP3 initramfs source and firmware staging

The canonical recovery initramfs is generated by the default Buildroot profile.
The project-owned sources are under boot/initramfs and are installed by the
op3-initramfs Buildroot package:

- init and etc/inittab
- sbin/init_mainline.sh and sbin/run_recovery.sh
- usr/bin/init_audio_mainline.sh
- static feed_entropy and nc helpers
- the tracked Wi-Fi and audio route helpers

Buildroot writes the complete image to
out/buildroot-op3-recovery/images/rootfs.cpio.gz. It is the ramdisk input for
scripts/pack-boot.sh. The same target/ directory can be staged as the
persistent /newroot payload.

The Qualcomm, A530, and ath10k files are not source code and remain external,
hash-verified inputs. Run scripts/stage-op3-initramfs-firmware.sh to merge them
under artifacts/op3-initramfs-firmware before the owner runs Buildroot.

The old scripts/make-reproducible-base-initrd.sh,
scripts/make-firmware-provenance-initrd.sh, and
scripts/make-recovery-browser-initrd.sh are retained for historical
experiments only. They consume or overlay the standalone reference initrd and
are not part of the canonical rebuild.
